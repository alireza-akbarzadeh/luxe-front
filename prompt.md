# Task: Build a Modern Vendor Dashboard for an E-commerce Marketplace

You are a Senior Product Designer and Senior Frontend Engineer.

Build a production-ready Vendor Dashboard that allows merchants to manage every aspect of their online business.

The dashboard should be modular, scalable, beautiful, and enterprise-ready.

Think of a combination of:

- Shopify Admin
- Amazon Seller Central
- Etsy Seller Dashboard
- Stripe Dashboard
- Vercel Dashboard
- Linear

The interface should feel premium, clean, modern, and extremely easy to use.
